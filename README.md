# Plataforma de Treinamentos

Projeto estático em HTML, sem etapa de build ou dependências externas.

- **`index.html`** — página inicial para GitHub Pages.
- **`plataforma_treinamentos.html`** — fonte da plataforma EAD. O menu Faturamento possui duas trilhas próprias: **Abertura de Faturamento** e **Faturamento Manual**. Treinamento profissional em duas trilhas, com 5 aulas guiadas por rota (40 min cada). As capturas originais do caderno estão incorporadas em resolução nativa e podem ser ampliadas; explicações de campo/abas e exercícios foram alinhados à interface UseCloud consultada em 29/10/2026, em modo de leitura, sem criar/alterar registros. Inclui roteiro do instrutor, prática, checklist, diagnóstico do Monitor e referência técnica. O caderno original sugere 75 minutos; a divisão ampliada da plataforma reserva cerca de 80 minutos para as duas rotas.
- **`treinamento_faturamento_usecloud.pdf`** — caderno de apoio do participante sobre emissão de NF-e no UseCloud (21 páginas; duração sugerida de 75 minutos), fonte completa das trilhas de Faturamento; o original permanece disponível como material de consulta complementar.
- **`treinamento.html`** — apresentação de treinamento anterior, preservada.

## Uso local

Abra `index.html` ou `plataforma_treinamentos.html` em um navegador moderno. O progresso das aulas e regras importadas ficam armazenados localmente no navegador; não são sincronizados entre dispositivos.

## Publicação no GitHub Pages

Em **Settings → Pages**, escolha a branch `main` e a pasta `/ (root)`. O GitHub Pages usará `index.html` como página inicial.

## Observações

O laboratório tributário tem finalidade educacional e não substitui validação fiscal. A trilha de emissão de NF-e é material de treinamento: pratique em papel ou em ambiente autorizado, sem gravar documentos reais. Confirme a versão atual do sistema, as permissões e o procedimento interno antes de qualquer operação.
