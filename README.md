# Plataforma de Treinamentos

Projeto estático em HTML, sem etapa de build ou dependências externas.

- **`index.html`** — página inicial para GitHub Pages.
- **`plataforma_treinamentos.html`** — fonte da plataforma EAD, com sessões e microtrilhas, incluindo o menu Faturamento separado em Abertura de Faturamento e Faturamento Manual.
- **`treinamento_faturamento_usecloud.pdf`** — caderno de apoio do participante sobre emissão de NF-e no UseCloud (21 páginas; duração sugerida de 75 minutos), consultado pela trilha de Faturamento.
- **`treinamento.html`** — apresentação de treinamento anterior, preservada.

## Uso local

Abra `index.html` ou `plataforma_treinamentos.html` em um navegador moderno. O progresso das aulas e regras importadas ficam armazenados localmente no navegador; não são sincronizados entre dispositivos.

## Publicação no GitHub Pages

Em **Settings → Pages**, escolha a branch `main` e a pasta `/ (root)`. O GitHub Pages usará `index.html` como página inicial.

## Observações

O laboratório tributário tem finalidade educacional e não substitui validação fiscal. A trilha de emissão de NF-e é material de treinamento: pratique em papel ou em ambiente autorizado, sem gravar documentos reais. Confirme a versão atual do sistema, as permissões e o procedimento interno antes de qualquer operação.
