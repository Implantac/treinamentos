# Plataforma de Treinamentos

Projeto estático em HTML, sem etapa de build ou dependências externas.

- **`index.html`** — página inicial da plataforma atual (cópia de `plataforma_treinamentos.html`, pronta para GitHub Pages).
- **`plataforma_treinamentos.html`** — arquivo-fonte da plataforma EAD, com microtrilhas, laboratório didático e referências tributárias.
- **`treinamento.html`** — apresentação de treinamento anterior, preservada.

## Uso local

Abra `index.html` ou `plataforma_treinamentos.html` em um navegador moderno. O progresso das aulas e regras importadas ficam armazenados localmente no navegador; não são sincronizados entre dispositivos.

## Publicação no GitHub Pages

No repositório, abra **Settings → Pages**, escolha a branch `main` e a pasta `/ (root)`. O GitHub Pages usará `index.html` como página inicial.

## Observações

O laboratório tributário tem finalidade educacional e não substitui validação fiscal. As referências oficiais e os limites de cobertura estão descritos na própria plataforma.
